# Support Ticket Resolution Assistant

Semantic triage and grounded resolution drafting for support tickets (Use Case 2).

**Live demo:** https://support-ticket-assistant-ddpuqm9pyfbqxuzrefbbxt.streamlit.app
(The app sleeps when unused; the first request after waking takes about a minute.)

## Status
- Days 1-5: data analysis, hybrid retrieval, triage, grounded drafting, confidence lanes, judge validation.
- Day 6: FastAPI backend, Streamlit agent screen, Docker setup, live deployment on Streamlit Community Cloud.
- See `docs/decisions.md` for every design decision with evidence, and `reports/` for all evaluation results.
